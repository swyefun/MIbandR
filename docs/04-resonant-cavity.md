# 04 — 空心容器共鸣：亥姆霍兹共振与实测方法

## 观察：放空心容器里效果特别好

LRA 单独在空气中推空气效率极低（声阻抗严重失配）。放进空心容器后，容器壁/开口变成大面积辐射面，声音显著变大。这不是凭空放大能量，而是**辐射效率提升 + 腔体储能**。

## 机制：两级共振叠加

1. **LRA 机械共振**：在 f0 处振幅最大。
2. **容器声学共振**：亥姆霍兹共振（f_H）处辐射最强。
3. f0 ≈ f_H 时两级增益相乘——这就是"特别好"的原因。

## 亥姆霍兹公式

```
f_H = (c / 2π) · √( A / (V · L) )
```

- c：声速 ≈ 343 m/s
- A：开口截面积
- V：腔体容积
- L：颈长（含端部修正）

调音规律：
- **降频**：增大容器 / 减小开口 / 加长瓶颈
- **升频**：缩小容器 / 加大开口 / 缩短瓶颈
- 加水可减小有效容积 → 升频，可作无级微调手段

## 常见容器估算（c=343）

| 容器 | 开口 | 颈长 | f_H |
|---|---|---|---|
| 500 ml 瓶 | Ø2 cm | 5 cm | **194 Hz** |
| 1 L 罐 | Ø2 cm | 3 cm | **177 Hz** |
| 100 ml 小罐 | Ø1 cm | 3 cm | 279 Hz |
| 100 ml 小罐 | Ø1 cm | 1 cm | 484 Hz |

若马达 f0≈175 Hz，500 ml 瓶 / 1 L 罐正好匹配。若 f0≈250 Hz，需要小得多的开口：

| 容积 | 颈长 | 250 Hz 所需开口直径 |
|---|---|---|
| 1 L | 3 cm | 2.8 mm |
| 500 ml | 5 cm | 2.6 mm |
| 500 ml | 3 cm | 2.0 mm |
| 250 ml | 2 cm | 1.2 mm |
| 100 ml | 3 cm | 0.9 mm |

**注意**：若手边瓶子开口是 2 cm 量级（f_H 仅 180–200 Hz）却效果特别好，可能耦合机制不是标准亥姆霍兹，而是腔体驻波模态或壳体弯曲共振（把手环整个放进去时尤其如此）。

## 相关研究

EPFL 团队的声驱动微型船（《科学进展》）：对比偏心马达、压电片、音圈和 **LRA** 后，选 LRA 当换能器（有效区间 230–700 Hz），贴在 3D 打印的**钟形谐振腔平底**上——关键结论："换能器贴在与颈口轴向垂直的平面上，结构声就能激发亥姆霍兹共振"。做了 455/540/630 Hz 三个腔，推力随驱动电压线性增长。工程上验证了 LRA + 共振腔路线。

## 实操建议

- 先把腔体共振调到 f0：公式估算，再加水/改开口微调，边调边听最响点。
- 贴法：LRA 刚性粘接在容器壁外侧（谐振腔平面段），与开口轴垂直的面耦合最好。
- 材质：玻璃、金属、硬塑料刚性腔体 Q 值高、清亮；软材料阻尼大吃掉增益。
- 想覆盖更宽频段：多腔（不同 f_H）或宽带 LRA。
- 代价：音染重（只在共振点附近响），适合单音/提示音/节奏，全频音乐仍需 EQ 或多执行器。
