# Band 11 马达 ABI 探测结论（真机实测，2026-11-21）

测试载体：vibe_player 模块 v1.1/v1.2（应用列表条目「MIbandR Vibe」，直调
`CANOPUS_SUP_VIBRATOR_RUN`，固件 4.100.179）。测量手段：手机频谱 App
（对数频率轴）录振动声 + 像素级频谱图量化分析。

## 已钉死的事实

| 维度 | 结论 | 证据 |
|---|---|---|
| 时间粒度 | **1 ms 全部有感**（100→50→20→10→5→2→1 ms 递减序列无失感点） | 时长下限测试，rc=13 全接受 |
| offset 字段 | **被忽略**，段纯顺序播放（3s 静默基底 + offset 500/1500/2500 脉冲 → 实际先静默 3s 再连三下） | offset 调度测试，rc=4 |
| 段时长 | 600ms 段 + 300..1000ms 递增静默全部按设计播放，scale ≈ 0.05 px/ms | flags 扫描 v2 频谱间距 55→73.5px 单调递增，与 900→1500ms 完全吻合 |
| f0 | **≈ 250-260 Hz**（与安和 FZ-HD00/FZ-HB01 250±10 Hz 规格吻合） | 两个频谱图基频柱位置 + 标定 |
| flags 字节 | **非 no-op**：改变驱动输出（能量 ±10~30%、二次谐波形状），但语义不是干净的双极性掩码 | flags 扫描 v2 + A/B 配对量化 |

## flags 量化数据

A/B 配对（30ms 参照 flags=0 vs 30ms flags=bit，全幅度；能量比 bit/ref）：

```
0x01: 0.91   0x02: 1.05   0x04: 1.19   0x08: 1.17
0x10: 0.99   0x20: 1.29   0x40: 1.23   0x80: 1.13
```

- 0x20 / 0x40 稳定 +23~29%（高于 ±15% 噪声底），0x04 / 0x08 / 0x80 +13~19%。
- 0x01 反而 -9%（唯一低于参照的位）。
- flags 扫描 v2 的谐波形状：0x08 / 0x20 的二次谐波（2f0）几乎消失
  （能量比其他位低一个量级），0x01 / 0x02 的 f0 能量高约 20%。

**解读**：flags 更像固件内部的驱动模式/包络代码（影响波形形状与增益的组合），
而非简单的位掩码。单次测量噪声 ±10~15%（手持/麦克风距离漂移），单 bit 语义
需要重复测量才能定死。

## 对上层应用的意义

1. 主控制面 = 每段 amplitude 0-255 + 时长 1ms 粒度 + 任意段数串联 → 足够
   复刻原厂级别的幅度包络效果（原厂同样没有频率控制权，LRA 谐振驱动）。
2. flags 可以作为**经验性增益/音色微调**使用：想要更冲的短脉冲优先试
   0x20 / 0x40；0x01 用于需要收敛的段落。
3. offset 不可用于调度；多段背靠背串联 + 静默段（amplitude=0）是唯一的
   时间轴表达方式。

## 待办（可选）

- flags 单 bit 语义：每种 bit 重复 5 次取中位数（可在固定容器里录）。
- f0 精测：vib-probe 容器耦合法 + 本次频谱标定可以交叉验证 250 Hz 假设。
- 幅度分辨率：0-255 逐级扫描确认固件是否线性透传（当前只测了 16/64/128/200/255）。
